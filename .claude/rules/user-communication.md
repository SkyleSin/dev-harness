# 사용자와 소통하는 규칙

사용자에게 보내는 글(채팅 보고, 질문, 승인 요청, `decisions.md` 항목, 최종 정리)에 적용하는 규약이다. 에이전트끼리 주고받는 산출물(`01`~`05`)은 대상이 아니다.

## 쓰는 방식

- 결론을 맨 앞에 쓴다. 그다음에 근거와 세부를 쓴다.
- 완전한 문장으로 쓴다. 조사와 서술어를 생략한 명사 나열, 화살표(`→`)로 이은 줄임 표현, 약어로 문장을 대신하지 않는다.
- 내부 용어(`Gate 1`, `T02`, `blocked`, `baseline-proposal`, `NT` 같은 약어)는 처음 나오는 자리에서 한 번 풀어 쓴다. 풀이 없이 단계 번호나 파일 이름만 던지지 않는다. 파일을 가리킬 때는 무엇이 들어 있는 파일인지 함께 적는다.
- 에이전트가 돌려준 반환문을 그대로 붙여넣지 않는다. 반환문은 압축된 글이므로 사용자가 이해할 수 있게 풀어서 전달한다.
- 한 번에 한 주제만 묻는다. 서로 무관한 질문은 나눈다.
- 모르는 것은 모른다고 쓰고, 추측은 추측이라고 밝힌다.

## 묻는 방식

질문과 승인 요청은 이 순서로 쓴다.

1. 배경: 왜 이 질문이 나왔는지 (사용자가 앞 맥락을 기억하지 못해도 읽히게)
2. 선택지: 고를 수 있는 것을 각각 한 문장으로
3. 권장안과 이유: 하나를 권장한다면 그 이유
4. 선택에 따른 결과: 각 선택을 하면 무엇이 달라지는지

## 어디에 묻는가

- 실행 폴더(`RUN_DIR`)가 있으면 승인과 결정은 `decisions.md` 의 항목으로 등록한다. 채팅에는 "`decisions.md` 에 ○건을 등록했습니다. 답을 적어 주세요" 정도의 안내만 쓰고, 질문 내용을 채팅에 되풀이하지 않는다. 형식은 `.claude/docs/runs.md` 의 '결정과 승인 기록' 절.
- 사용자가 채팅으로 답해도 받는다. 이때는 해당 항목의 `->` 줄에 답을 옮겨 적어 기록이 파일에 남게 한다.
- 실행 폴더가 생기기 전의 질문(대상 폴더가 불분명할 때, 이어서 할지 새로 할지 고르기)은 채팅으로 묻는다. 이때도 위의 쓰는 방식과 묻는 방식을 따른다.
